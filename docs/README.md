# Documentation Directory (`docs/`)

## 1. Folder Responsibility
The `docs/` directory serves as the centralized repository for all engineering specifications, system architecture designs, database schemas, API contracts, evaluation benchmarks, and technical reports for the Enterprise Intelligence Platform. It maintains the project's technical documentation and deliverables required for the assessment submission.

## 2. Subdirectories and Planned Contents

- **`architecture/`**
  - **Planned Contents:** System architecture diagrams (C4 / component diagrams), data ingestion pipelines, end-to-end RAG workflows, AI agent decision trees, and conversational memory flowcharts.
  - **Status:** PLANNED / NOT IMPLEMENTED.

- **`database/`**
  - **Planned Contents:** Relational schema documentation, PostgreSQL table definitions, `pgvector` index configurations (HNSW/IVFFlat), and data retention policies.
  - **Status:** PLANNED / NOT IMPLEMENTED.

- **`api/`**
  - **Planned Contents:** OpenAPI / Swagger specifications, REST endpoint schemas, request/response payload examples, and error-handling standards.
  - **Status:** PLANNED / NOT IMPLEMENTED.

- **`evaluation/`**
  - **Planned Contents:** 20+ question evaluation dataset with ground-truth answers, evaluation methodology descriptions, RAGAS/DeepEval metric configurations, and test benchmark outputs.
  - **Status:** PLANNED / NOT IMPLEMENTED.

- **`reports/`**
  - **Planned Contents:** AI tool usage disclosure report, engineering trade-off logs, assessment milestone reports, and deployment verification documentation.
  - **Status:** PLANNED / NOT IMPLEMENTED.

## 3. Connection to the Overall Platform
This directory connects to the implementation by providing the architectural blueprint, data contracts, and verification criteria for both `backend/` and `frontend/`. It ensures that every module built directly adheres to the requirements specified in the technical assessment.
